## 🌟 Overview

Welcome to the repository for **Nikhil Dhankar's** personal portfolio website. Built with **React**, **JavaScript**, **Vite**, and **Tailwind CSS**, this portfolio showcases full-stack and backend projects, technical skills, career timeline, and an interactive CLI terminal experience.

### ✨ Key Features
- 🚀 **Interactive Terminal Mode**: Switch between graphical UI and an interactive command-line interface with custom commands (`whoami`, `about`, `projects`, `skills`, `themes`, `contact`).
- 🎨 **Sleek Dark Theme & Glassmorphism**: Clean modern design with smooth animations powered by Framer Motion.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile viewing.
- 🔒 **Zero Vulnerabilities & Hardened Security**: Strict security headers and safe external link attributes.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, JavaScript (ESM / JSX)
- **Styling**: Tailwind CSS, PostCSS
- **Animations**: Framer Motion
- **Icons**: Lucide Icons
- **Bundler & Tooling**: Vite
- **Deployment**: GitHub Pages & Netlify

## 💻 Local Development

Clone the repository and install dependencies to run the app locally:

```bash
# Clone repository
git clone https://github.com/Nikhildhankar/portfolio.git

# Navigate to project folder
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be running at `http://localhost:5173`.

### 📦 Build for Production

```bash
# Generate production build in /dist
npm run build

# Preview production build locally
npm run preview
```
